敌军自北营城楼涌出,沿楚河汉界的行军道直扑你的帅棋。
你手里没有弓箭塔,只有一盒象棋——车走直线、炮要翻山、马跳日字,
把棋子拖上谷地布阵,同型同阶两两**合军升阶**,顶住五十关的兵锋。

## 四种玩法

| 模式 | 内容 |
|---|---|
| **闯关** | 50 关五卷,每 5 关一章、章章必换地图:楚河汉界 / 长驱直入 / 三管齐下 / 万流归宗 / 垓下之围;后 41 关由确定性生成器编排,重载逐字节一致 |
| **无限** | 波次程序生成、水军楼船自河上来袭,血战至帅陨;后期精兵化,质量不再封冻 |
| **对战** | 双人同屏 + AI 对手(会发展、会带军械兵符),胜负计入段位 |
| **集市** | 局外成长:12 件军械、六种兵符,每件一套机制,不是纯加数值 |

## 特色

- **象棋即塔防**:七种棋子各依走法施展攻击,布阵与合成是守住帅棋的关键
- **七支特殊军**:羊角士 / 连环马 / 担竿炮 / 巡河炮 / 飞相局 / 过河兵 / 骑河车——双格连体、独门机制、杀敌经验升级
- **零美术资产**:全部画面由 Canvas 程序绘制(河面流光、城楼火盆、受击红幕、结算朱印),无一张图片素材
- **零联网**:纯离线单文件,构建产物 154 KB(gzip 57 KB),双击即玩
- **手机可玩**:Pointer 事件统一鼠标触摸,加主屏可全屏玩
