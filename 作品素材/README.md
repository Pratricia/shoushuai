## 采集方式(可复现)

- 摆景:QA 钩子 `window.__game` 摆 L26 场景(南岸三行满布、羊角士成军、
  楼船 6 秒内泊桥未沉、敌军 0-5.6s 分 12 批入场铺满纵深);
- 抓帧:`g.render()` 同步渲染后立即 `canvas.toDataURL()`,经本机回环(127.0.0.1)
  同步 XHR 直传落盘——不经过截图工具,帧零漂移;
- 定位裁剪:画布含信箱边条,以「中线一行扫描边条→内容分界」自校准定位游戏区
  (宽高比 720/1280 校验,自动适配 DPR 缩放),再高质量重采样至目标尺寸。
